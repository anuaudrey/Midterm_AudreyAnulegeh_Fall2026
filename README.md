# Library Management System

## Description
This Java project manages library members and staff. It demonstrates inheritance, abstraction, polymorphism, method overloading, method overriding, and interfaces. It also calculates staff compensation, late fees, and manages book reservations.

## Requirements
- Java JDK 21 or later
- Eclipse IDE or a terminal

## How to Compile and Run

**Using Eclipse:**
1. Open the project in Eclipse.
2. Open `Main.java`.
3. Right-click and select **Run As → Java Application**.
